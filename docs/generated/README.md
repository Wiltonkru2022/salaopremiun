# Documentos Gerados

Esta pasta é reservada para relatórios produzidos automaticamente por scripts de auditoria.

Eles **não são fonte manual de arquitetura** e podem ficar obsoletos depois de mudanças no código. Gere novamente o relatório necessário a partir do checkout atual antes de usá-lo como evidência.

Exemplo:

```bash
npm run audit:admin-client-inventory
```

Não edite artefatos gerados manualmente para “fazer passar” auditoria; corrija o código/configuração ou o gerador.
